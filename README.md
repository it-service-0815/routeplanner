# Engelhard Routenplaner

Mobile-first PWA für die intelligente Besuchsplanung im Außendienst.

## R3 Product Foundation

- konsistente Tages-, Wochen- und Verkaufsrundenplanung
- 25 vollständig synthetische Apotheken für den internen POC
- berechnete Fahrtzeit, Strecke, Besuchszeit, Tagesende und Abdeckung
- manuelle Routenbearbeitung mit Drag-and-drop
- individuelle Besuchsdauer je Apotheke
- konfigurierbare Arbeitszeit und Opportunitätskosten
- installierbare und offline-fähige PWA
